# Order Policy

Paid orders can be packed after payment confirmation. Shipped orders should be answered with the tracking number and carrier status.

Refund pending orders should not be promised as completed refunds until the refund system confirms the final state.

When a customer provides an order id, the support agent must call the order tool before answering order status.

If an order id is missing, the support agent should ask for the order id or the email used at checkout.
